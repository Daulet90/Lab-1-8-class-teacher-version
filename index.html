Лабораторная работа №1

«Сравнение количеств теплоты при смешивании воды разной температуры»

Версия для учителя — ключ с автоматическим расчётом

Расчётные формулы

  • Q = c·m·|t − t₀| — количество теплоты
  • Q₁ = Q₂ — условие теплового баланса
  • ΔQ = Q₂ − Q₁ — абсолютная разность количеств теплоты
  • ε = (ΔQ / Q₂)·100% — относительная погрешность

Столбец «Образец» — эталонный пример, выданный учащимся уже решённым. «Вариант 1» и «Вариант 2» — данные, розданные учащимся для самостоятельного расчёта; здесь они посчитаны автоматически для быстрой проверки тетрадей. Значения можно менять — результаты пересчитаются сразу.
